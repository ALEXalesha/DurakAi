**DurakAi 1.0.5: fixes after the charts review (shared aikit 0.2.2).**

- In a narrow window the legend of "Results by AI level" moves to a second line, and the "100%" number above a full bar stood right against it. Numbers above bars now have their own room; a new law checks that no chart labels overlap, in both themes, both languages, narrow, wide and 4K windows.
- A long journal (thousands of games) no longer slows the statistics page down: a dense line is drawn as a band from the lowest to the highest value of each screen column - tens of milliseconds instead of seconds per repaint.
- The mutation check runs the tests without a mutant first and stops if they are red; a new law checks that every mutant line is found exactly once. 328 checks, 107 mutants.

Files: `DurakAi-1.0.5-setup.exe` and `DurakAi-1.0.5-portable.zip`. The builds are not code-signed, so SmartScreen may warn on first start.

**DurakAi 1.0.5: исправления после проверки графиков (общий aikit 0.2.2).** Число «100%» над столбиком больше не стоит на легенде, ушедшей в узком окне на вторую строку; закон: надписи графиков не налезают друг на друга в обеих темах, на двух языках, в узком, широком и 4K-окне. Тысячи партий в журнале рисуются за десятки миллисекунд, а не секунды. Мутационная проверка сначала гоняет проверки без мутанта; закон «строка каждого мутанта ровно один раз». 328 проверок, 107 мутантов. Сборки без подписи кода, SmartScreen может предупредить при первом запуске.
